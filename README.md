# Little Lemon Restaurant - React Capstone Project

A responsive restaurant booking web application built using React as part of the Meta Front-End Developer Capstone Project.

## Project Overview

Little Lemon is a Mediterranean restaurant website that allows customers to reserve a table through an interactive booking form.

The application demonstrates React concepts including:

- Component-based architecture
- State management using React Hooks
- Form handling
- Client-side validation
- Accessibility practices
- Unit testing


## Features

### Table Reservation Form

Users can:

- Enter their name
- Select reservation date
- Choose available time
- Select number of guests
- Submit a booking request


### Form Validation

The application handles:

- Empty field validation
- Invalid guest numbers
- Past date prevention
- Success and error messages


### Accessibility

Implemented:

- Semantic HTML elements
- Proper labels using htmlFor
- ARIA attributes
- Keyboard-friendly form controls


### Responsive Design

The application works on:

- Desktop screens
- Tablets
- Mobile devices


## Technologies Used

- React.js
- JavaScript ES6+
- HTML5
- CSS3
- React Testing Library
- Jest
